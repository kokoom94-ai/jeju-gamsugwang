# 🍊 어디레 감수광?

> 숙소와 가고 싶은 곳만 담으면 제주 지리에 맞춘 일자별 동선을 설계해주는 제주여행 플래너

**🔗 https://jeju-gamsugwang.vercel.app**

이름은 제주 방언 인사 **"어디레 감수광?"(어디 가세요?)** 에서 가져왔습니다. 어디로 갈지 묻는 말이, 어디로 갈지 답해주는 서비스가 됐습니다.

제주는 생각보다 큽니다. 서울의 세 배쯤 되는 섬에서, 모아둔 여행지들을 어떤 순서로 도는 게 좋을지는 매번 고민거리였습니다. 여행 커뮤니티와 SNS에서 장소를 모으는 것까지는 다들 잘하는데, 그걸 동선으로 엮는 일은 지도 앱을 오가며 수작업으로 해야 했습니다. 유명OTA에서는 플래너 기능이 도입되고 있지만 자사상품 연계다보니 그마저도 쉽지 않죠. 여행설계 과정을 자동화해보고 싶어서 만든 개인 사이드 프로젝트입니다.

## 어떻게 동작하나

숙소를 정하고, 가고 싶은 곳을 담고, 일정(당일~4박5일)을 고르면 끝입니다. 나머지는 프로그램이 합니다.

- **제주 지리 기반 동선 설계** — 섬 중심 방위각으로 장소를 정렬해 한 방향으로 도는 흐름을 만들고, 시계/반시계 양방향을 계산해 총거리가 짧은 쪽을 택합니다. 각 일자는 완전탐색으로 방문 순서를 최적화합니다.
- **항공 시간 맞춤** — 입도·출도 항공편과 체크인/체크아웃 시간을 넣으면, 첫날은 공항→경유지→숙소, 마지막 날은 체크아웃→경유지→공항 구조로 시간을 배분합니다.
- **구간별 이동수단 3종** — 자차·도보·버스 예상 시간을 함께 표시하고, 버스는 제주 노선 체계 기반 추천 노선과 네이버지도 길찾기 링크를 제공합니다.
- **자유로운 코스 편집** — 순서 변경, 다른 날로 이동, 빼기(보관함), 검색해서 중간 삽입(최소 우회 지점 자동), 일자별 재최적화.

네 단계 탭으로 여행 준비를 이어갑니다.(탭 별로 입력이 완료되어야 다음으로 넘어갑니다.)

| 탭 | 내용 |
|---|---|
| ① 코스 | 숙소·장소·일정 입력 → 자동 동선 설계 |
| ② 편의시설 | 코스 주변 약국·병원·주유소·편의점 등을 네이버 플레이스로 검색, 지도 표시 + 코스 삽입 |
| ③ 비용 | 유류비(휘발유/경유/전기) + 장소별 입장료 × 인원 → 예상 경비 |
| ④ 마무리 | 일자별 최종 코스(클릭→지도 포커스), AI 이미지 프롬프트, 도로 CCTV 201곳 표시 |

작성한 계획은 브라우저에 자동 저장되고, `.json` 파일로 내보내 다른 기기나 동행자와 공유할 수 있습니다.

## 데이터

- **장소 검색**: 네이버 지역검색 API (서버리스 프록시 경유)
- **인기 순위**: 제주관광 빅데이터 플랫폼 내비게이션 데이터(2026.1~7 관광객 도착 기준) TOP 30, `popular.json`으로 월간 갱신
- **편의시설**: 네이버 플레이스 검색 기반 (OSM Overpass 폴백)
- **CCTV**: 제주 교통정보센터 오픈API 201곳 (서울 리전 직접 호출) + 국가교통정보센터 ITS (국도, 영상 재생 포함)
- **지도**: Leaflet + OpenStreetMap (경로·시간은 직선거리 기반 추정치)

이동·체류 시간과 비용은 모두 추정치이며, 화면에 해당 고지를 표기하고 있습니다.

## 기술 스택

바닐라 JavaScript 단일 HTML 파일 + Vercel Serverless Functions(서버리스 프록시 3개, 서울 리전)로 구성했습니다. 프레임워크 없이 가볍게 유지하는 것이 목표였고, 전체가 정적 배포라 서버 비용이 들지 않습니다. 개인정보는 서버에 저장하지 않으며 계획 데이터는 사용자 브라우저에만 남습니다.

```
index.html          # 앱 전체 (UI + 동선 알고리즘)
popular.json        # 인기 순위 데이터 (월간 갱신)
og-image.png        # 카카오톡·SNS 공유 미리보기 이미지
api/
  naver-search.js   # 네이버 지역검색 프록시
  facilities.js     # OSM Overpass 프록시 (폴백)
  cctv.js           # 제주+국가 CCTV 통합 프록시
vercel.json         # 함수 실행 지역: 서울(icn1)
```

함수가 서울 리전(icn1)에서 실행되므로, 해외 IP를 차단하는 제주 공공 API도 별도 중계 없이 직접 호출합니다.

## 직접 배포하기

Vercel에 이 저장소를 Import하고 환경변수만 넣으면 됩니다. 자세한 절차는 [docs/DEPLOY.md](docs/DEPLOY.md) 참고.

| 환경변수 | 발급처 | 용도 |
|---|---|---|
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | [NAVER API HUB](https://www.ncloud.com/product/applicationService/naverApiHub) | 장소·편의시설 검색 |
| `JEJU_ITS_CODE` | [제주 교통정보센터](https://www.jejuits.go.kr) 오픈API | 교차로 CCTV 201곳 |
| `ITS_API_KEY` | [국가교통정보센터](https://www.its.go.kr) 오픈API (선택) | 국도 CCTV 영상 재생 |

키가 없어도 내장 여행지 DB로 기본 동작합니다.

## 한계와 계획

이동 시간은 도로 실측이 아닌 직선거리 × 보정계수 추정이라 실제와 차이가 있습니다. 제주 교차로 CCTV는 현재 위치만 표시되며, 실시간 영상 재생은 교통정보센터 화상 API 연동 시 추가될 예정입니다. 다음 단계로 네이버 지도 API 전환(실측 경로), C-ITS 데이터 연동(주유소 가격·EV 충전 정보), 순위 데이터 자동 갱신을 생각하고 있습니다.
